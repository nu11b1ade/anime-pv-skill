# 制作质量与审片

制定质量目标时读取本文件；制作中按阶段查阅。约束可观察的结果与证据，构图、画风、镜头数量、动画手法和工具由模型结合项目判断。

## 阶段 1：确定质量目标

用简短记录说明成片要传达的情绪、主要视觉焦点、质量参考及需要保留的特征。复刻以原片的具体时间段为依据；创作说明参考中采用的构图、用色、排版或节奏，并明确自主设计范围。没有外部参考时先提出可验证的视觉目标，用样片形成共识，不强求用户另找参考。

除了避免缺陷，也写下让本片达到顶级的具体抓手，例如某段的节奏爆点、标题演出、光效基调；这是打磨方向，不是固定清单。有参考片时可以用 `media.py cuts` 测量镜头时长和切镜节奏，作为可对照的目标。

识别可能决定成败的镜头，例如转头、复杂遮挡、强透视、连续表演或精确字形动画。记录各自需要验证的素材与实现条件，阶段 2 优先解决；无法达到目标时用实际片段展示差距，不等到全片完成才暴露。

区分方向判断与制作缺陷。角色身份意外漂移、缺字、非预期穿帮、边缘污染、意外闪烁或关键信息无法辨读，应在送审前主动处理。有意的抽帧、夸张形变、粗糙纹理或瞬时文字按镜头意图与参考判断，不机械判错。用户批准方向或上一版本，不代表接受新引入的缺陷。

## 阶段 2：镜头设计与素材

多镜头项目建立轻量镜头记录，可复用现有分镜或工程数据；单镜头直接记录同样的关键信息，无需另造表格。

| 记录项 | 用途 |
| --- | --- |
| 稳定镜头 ID、起止时间与时间基 | 定位制作、回改和验收；可变帧率参考使用实际时间戳 |
| 镜头作用与主要视觉焦点 | 说明观众此刻应看到什么，以及与前后镜头的关系 |
| 构图、主要文字、运动与转场意图 | 把视觉方案连接到时间轴，避免只罗列特效名称 |
| 素材 ID / 版本与依赖决定 | 找到实际采用素材及回改影响范围 |
| 难点、验证片段和当前未决项 | 让尚未解决的问题保持可见 |

复刻记录原片时间对应关系、关键运动/遮挡事件和获准差异。创作检查镜头间的情绪推进、信息密度与视觉变化；有用户音频时标记重要音乐事件，无音频时按视觉节奏设计，不自行补音乐。不要求每拍切镜或每个镜头都运动。

素材进入镜头前，按实际用途检查：

- **角色一致性**：发型、脸部特征、服装结构和标志物与角色基准一致；跨镜头检查线条、明暗和色彩。需要新角度或表情时沿用基准验证，不要求无用途的完整设定集。
- **运动所需空间**：移动、缩放和视差所需的画面余量足够；遮挡后显露区域已补全，需要独立运动的部分能分层或用适合的方式控制。
- **有效细节**：在镜头最大放大和实际裁切下检查清晰度、线条及纹理，避免仅按原图像素尺寸判合格。
- **合成边缘**：在实际背景上检查透明边缘、发丝、半透明物和遮罩接缝；必要时核对 alpha 解释及颜色处理。生图结果有 alpha 通道不代表合成已合格。
- **文字与图形**：需要精确字形、布局或独立运动时优先用文字/矢量层；画进图内的文字和纹理化图形按其实际用途验收，不强制重做。

采用素材保留版本与来源，缺陷修正尽量保留已合格部分。局部生图编辑仍要检查保护区域，不能假定遮罩外像素或角色特征完全不变。

## 阶段 2：动态样片的代表性

样片应覆盖能代表全片的视觉与运动，以及影响方案可行性的难点；两者可以在同一片段验证，不固定样片数量。涉及转场或遮挡的片段包含前后接续，不能只展示最有利的一帧。

关键样片通过拟用于最终交付的渲染链路输出，验证字体、透明度、动画时序及镜头效果。临时 HTML 或其他实现可用于探索；用于定案的效果必须在最终链路中复核。更换引擎或关键渲染设置后，复验受影响样片，不自动继承旧结论。

## 阶段 3–4：审片与返工

- **全片节奏**：以正常播放速度检查视觉焦点、文字阅读时间、镜头接续、重复感及有音频时的同步；覆盖完整片长。
- **局部质量**：高风险片段按交付分辨率、帧率和相关质量设置输出，检查边缘、细字、纹理、运动及转场。降低分辨率的预演只用于确认方向。
- **复刻对照**：同时间位置并排或叠加检查，结合连续播放判断；按批准范围解释角色替换差异。工程指标及音轨检查见 [工程与验收](production.md#三层验收)。

记录实际检查方式、文件版本和时间覆盖范围。只能读取静帧或抽样帧时如实标记；连续审阅未完成的项保留待验证，交给可播放审阅完成。胶片条、同时间点对照、切点对齐等手段见 [制作手法与工具](craft.md#动态自检手段)。

发现问题时记录镜头/时间位置、现象、影响、修正动作和复验结果，可直接附在已有镜头记录中。优先处理影响方向、身份、连续性或可读性的问题；每轮针对原因修正，保留较优版本，不盲目重复生图或不断追加特效。

同一问题反复无改善时，重新判断素材、分层、时序或实现路线；在已有授权内尝试合适的二维方法。涉及批准方向、允许差异或生图后端的改变，按原有批准规则处理。不能达标的项目要展示证据并说明限制，不能靠降低自检标准标记完成。

## 送审与交接

首次样片和后续阶段成果都先自检，再展示证据。自检分两步：先排除制作缺陷，再对照质量目标和参考，挑出最影响观感的一两处继续打磨（节奏、焦点、文字演出、光效与色调、转场动机），不停在“没有错误”。阻碍本阶段方向或可行性判断的问题未解决时，保持阶段未完成；预演可保留不影响判断的明确暂缺项，正式验收逐项核对。

交接只链接当前质量目标、镜头/素材记录、验证证据和未决缺陷；用户确认仍按 [交接规范](handoff.md) 记录。阶段内修正已授权范围内的制作缺陷由模型自主完成，不新增逐项审批，也不替用户作出最终验收决定。
