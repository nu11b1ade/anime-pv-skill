# 工程、预检与验收

## 预检

```sh
uv run <skill>/scripts/project.py preflight
uv run <skill>/scripts/project.py probe <参考视频>
```

预检不安装工具、不启动本地 AI、不读取密钥。报告系统、Python、uv、ffmpeg、ffprobe 和可选渲染工具存在性/版本及安装提示；存在性不等于完整可用性。根据技术路线验证字体、编码器、中文排版、透明度、色彩和一小段实际渲染。正式制作前重复检查发生变化的部分。安装指导适配当前系统；适用时用 Homebrew，Python 依赖用 uv 和锁文件。

## 可重渲染的最小工程约定

- 输入保留原件。素材 ID 与文件版本稳定，记录出处、生成提示词/参考、允许差异和依赖镜头；不要把在线临时 URL 当唯一素材。
- 明确画布、时间基、帧率、帧编号约定、色彩空间、透明度和字体来源。随机效果固定种子。可变帧率参考要分析时间戳，不假定帧号等距。
- 按效果选择程序化二维合成、HTML/SVG/canvas 或现有编辑工程；不为了套固定工具降低质量。HTML demo 若作为渲染来源，要由确定性的时间驱动动画，避免依赖录屏时的实际帧率。
- 命令和路径支持 macOS、Linux、Windows；Python 用 pathlib 与 subprocess 参数列表，避免 shell=True 和 Unix 专属管道。第三方引擎的可移植性单独记录，不把跨平台设计写成实机已验证。
- 工程运行说明保留入口、工作目录、依赖安装与精确渲染命令。锁定必要版本，实际试跑重渲染后再宣称可复现。

## 文件位置与临时目录

先确定 PV 项目绝对路径，再运行任何会产生文件的工具。初始化脚本创建 `tmp/` 和 `.cache/` 并加入项目 `.gitignore`；恢复旧项目时按需补建。工作目录设为项目根目录，显式指定下载、生图、抽帧、截图、日志、渲染和打包的项目内输出路径；仅改变工作目录不能约束工具的系统临时目录。

- 可丢弃的临时脚本、抽帧及中间文件放 `tmp/`；工具缓存放 `.cache/` 下各自的子目录。可复现所需脚本、输入、采用素材及批准证据放正式工程目录，不只留在临时目录。
- 调用命令前，将当前进程及其子进程的 `TMPDIR`、`TMP`、`TEMP` 设为项目 `tmp/` 的绝对路径；按工具支持情况设置 `XDG_CACHE_HOME=<项目>/.cache`、`UV_CACHE_DIR=<项目>/.cache/uv` 及渲染器自身缓存参数，并提前创建目录。Python 临时文件显式使用 `tempfile.TemporaryDirectory(dir=项目内临时目录)` 等参数，不依赖系统默认值。不修改用户全局环境配置。
- 不主动使用 `/tmp`、`/private/tmp`、系统临时目录或项目外共享临时目录存放任务文件。用户明确指定外部输出位置时遵从；内置工具或第三方工具无法配置位置时，将继续制作所需的结果及时复制到项目内，在交接中记录外部路径、原因及是否可清理。不要宣称环境变量能保证所有工具都遵守。
- 清理仅针对本任务已确认可再生成且无运行进程依赖的临时内容。不要把原始输入、唯一素材、批准证据或异步恢复状态当缓存删除；不要清空系统或其他项目的临时目录。打包清单排除 `tmp/`、`.cache/` 和交付包自身。

## 复刻音轨

先用 ffprobe 检查音轨、起始时间和时长，保证渲染视频覆盖相同时间轴。普通同起点素材可用下列命令作为起点，复杂偏移应按实际 PTS 设计映射：

```sh
ffmpeg -i silent-render.mkv -i reference.mkv -map 0:v:0 -map 1:a? -c:v copy -c:a copy final.mkv
```

不要默认加 -shortest 截断尾部，也不要为了 MP4 把音频转成 AAC。按要求保留音轨数量、顺序、语言/默认标记和同步偏移，必要时显式设置 metadata/disposition。容器能否承载原音频必须预检。无原音轨则不添加音轨。核查保存具体命令、输入/输出流信息，并按音轨比较编码数据包内容及时间关系；容器头不同不能用整文件哈希代替音轨核查。

## 三层验收

送审前按 [制作质量与审片](quality.md) 检查镜头、素材与动态证据；以下三层分别记录，不以其中一层通过替代其余层。

1. **工程检查**：可解码、分辨率、帧率/时间基、时长、帧数、无意外黑帧/掉帧、字体与素材齐备。复刻检查全部音轨复制和同步，自主创作无音频时检查 streams 中确实没有 audio。
2. **视觉与动态检查**：复刻在同一时间位置对照原片，覆盖镜头边界、关键帧、镜头运动、遮挡、排版、转场及连续播放。角色替换区域按批准差异判断；图像差分仅作定位辅助，不输出虚假的“还原度百分比”。创作对照已批准样片和完整预演，检查节奏与一致性。
3. **用户验收**：展示正式成片、差异和未通过项，请用户判断。自动检查或几张静帧不能替代动态审阅，也不能冒充用户批准。
