# 已知限制与后续验证

此处区分已知限制、待验证和可能改进，不代表已经承诺实现。

## 待验证

- 五类后端的真实账户、地区、模型、参考图/编辑能力和输出质量；当前以官方协议与离线测试为依据。
- 完整 PV 项目的四阶段交接、新窗口恢复及局部回改，用实际成果验证用户体验。
- 实际渲染引擎、字体、编码器和音轨复制在各目标平台的运行；离线 CI 不覆盖这些内容。

## 当前边界

- MiniMax 仅文生图与单张角色主体参考，不提供通用编辑；Gemini、Seedream 没有显式 mask 适配。
- OpenAI/Gemini 图片输入目前使用本地文件；Gemini 不处理 Vertex 鉴权和多轮会话续接。
- 不支持流式和图文混排输出；DashScope API profile 需要明确配置。
- unknown 提交需查账户后台，不能自动判断是否已经计费。同步接口没有通用任务查询，临时 URL 失效不保证恢复。
- 打包只按显式文件清单及文件名规则排除秘密，不是完整内容级秘密扫描。
- 同一个 job 目录不应并发操作；当前没有跨进程任务锁。

## 按实际需求评估

- 对响应部分成功/部分失败提供更细的结果记录，避免只统计成功图片。
- 增加更多代表性响应 fixture 和独立媒体验收工具。
- 对跨平台实际项目建立可公开的合成素材样例，避免带入未获公开授权的角色和音频。
